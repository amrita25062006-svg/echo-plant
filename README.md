# 🌿 Echo Plant

Echo Plant is an AI-powered plant monitoring and plant care assistant designed to help users track, analyze, and improve plant health. The application combines technology and smart recommendations to create an interactive plant management experience.

## ✨ Features

* 🌱 Plant health monitoring
* 📷 Plant image analysis
* 🤖 AI-based recommendations
* 💧 Plant care suggestions
* 📊 Easy-to-use dashboard
* 📱 Responsive and user-friendly interface

## 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/amrita25062006-svg/echo-plant.git
```

### Move into the project directory

```bash
cd echo-plant
```

### Create a virtual environment

```bash
python -m venv venv
```

### Activate the virtual environment

**Windows**

```bash
venv\Scripts\activate
```

**Linux/macOS**

```bash
source venv/bin/activate
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Run the server

```bash
python manage.py runserver
```

## 📸 How It Works

1. Upload a plant image.
2. The AI model analyzes the image.
3. The system detects possible plant issues.
4. Personalized recommendations are generated.
5. Users receive plant care suggestions.
